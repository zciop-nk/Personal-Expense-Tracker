SSEUM DESIGN SYSTEM

기록에 집중하는
작고 일관된 UI 언어

현재 씀에서 실제로 사용하는 토큰과 컴포넌트만 정의합니다. 새 화면을 만들기 전에 기존 컴포넌트로 해결할 수 있는지 먼저 확인합니다.

Principles

장식보다 기록, 새로운 스타일보다 재사용을 우선합니다.

기록이 먼저 보인다.
노란색은 핵심 CTA와 선택 상태에만 사용한다.
같은 역할은 같은 컴포넌트로 표현한다.
모바일은 축소판이 아니지만, 다른 디자인 언어를 만들지는 않는다.

CSS Governance

다시 무거워지는 것을 막기 위한 개발 규칙입니다.

같은 selector를 파일 끝에서 다시 덮어쓰지 않는다.
!important는 utility/외부 제약 외에는 추가하지 않는다.
상태 스타일은 컴포넌트 정의와 함께 관리한다.
새 UI 전에 기존 Button / Input / Card / Modal / Drawer 재사용 여부를 확인한다.
